# Information Retrieval and Web Search

This repository contains two core NLP/IR assignments implemented in Python:

1. **Corpus preprocessing with tokenization and Byte Pair Encoding (BPE)**
2. **Character bigram language identification (English, French, Italian)**

The project uses the Cranfield document collection and a multilingual sentence dataset for evaluation.

## Repository Structure

```text
.
├── cranfieldDocs/                    # Cranfield corpus files
├── languageIdentification.data/
│   ├── training/                     # Training files: English, French, Italian
│   ├── test                          # Test sentences (one per line)
│   └── solution                      # Gold labels for evaluation
├── preprocess.py                     # Main preprocessing + BPE script
├── preprocess.output                 # Generated stats and token frequencies
├── preprocess.answers                # Generated summary answers
├── languageIdentification.py         # Main language ID script
├── languageIdentification.output     # Predicted language per test line
└── languageIdentification.answers    # Accuracy report
```

> `preprocessc.py` and `languageIdentificationd.py` are alternate/older variants kept in the repo.

## Requirements

- Python **3.8+** (no external packages required)

## Task 1: Preprocessing and BPE

`preprocess.py` performs:

- SGML tag removal
- tokenization (including contraction handling)
- BPE merge-rule learning up to the target vocabulary size
- frequency reporting

### Run

```bash
python3 preprocess.py cranfieldDocs <vocabSize>
```

Example:

```bash
python3 preprocess.py cranfieldDocs 50
```

### Output Files

- **`preprocess.output`**
  - total token count
  - number of merge rules
  - first 20 merge rules
  - top 50 most frequent tokens
- **`preprocess.answers`** (generated by `preprocessc.py`)
  - summary answers such as minimum number of unique tokens covering 25% of corpus tokens

## Task 2: Language Identification (Bigram Model)

`languageIdentification.py` trains character-level bigram language models and predicts language line-by-line for the test set.

### Run

```bash
python3 languageIdentification.py languageIdentification.data/training languageIdentification.data/test
```

### Method

- Builds unigram and bigram character frequencies for each language
- Uses add-one smoothing
- Computes log-probability for each candidate language
- Chooses the highest-probability language per line

### Output Files

- **`languageIdentification.output`**  
  Predicted label format:
  ```text
  <line_number> <predicted_language>
  ```
- **`languageIdentification.answers`**  
  Overall accuracy compared to `languageIdentification.data/solution`

## Notes

- File encoding is handled as Latin-1 / ISO-8859-1 in scripts.
- Run commands from the repository root so output files are created in the expected location.
